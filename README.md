## Featured Projects

### Real-time Collaboration Platform

Full-stack workspace collaboration platform with real-time chat, channels, task management, polls, events, file upload, and voice/video infrastructure.

**Frontend:** `React 18` `TypeScript` `Vite` `Tailwind CSS` `Zustand` `React Query` `Socket.io Client`  
**Backend:** `Node.js` `Express` `TypeScript` `Socket.io` `MongoDB` `Redis` `JWT` `Cloudinary` `OpenAI`

**Highlights**

- Workspace and channel system with public, private, direct message, and voice channels.
- Real-time messaging with Socket.io rooms, message reactions, threading, and presence tracking.
- Task management with Work, Event, and Poll types, including RSVP and live result updates.
- Authentication with JWT, password hashing, role-based workspace access, and API validation.
- File upload via Cloudinary and AI assistant integration through OpenAI.
- Frontend and backend are separated into independent codebases for clearer deployment and maintenance.

### Fashion Recommendation App

Mobile AI app that detects fashion items and recommends outfits based on weather, location, and event context.

`Flutter` `Python` `YOLOv8` `OpenCV` `Firebase` `TensorFlow Lite` `REST API`

- Built a real-time fashion detection pipeline using a custom YOLOv8 model and OpenCV preprocessing.
- Developed a Flutter app with camera/gallery input, Firebase Auth, Firestore, Storage, FCM, and Crashlytics.
- Added an AI chatbot for contextual outfit suggestions using weather, GPS location, and user preferences.
- Implemented multilingual support with Flutter `gen-l10n`.

### Bird Recognition Mobile App

Mobile app for real-time bird species recognition using on-device image classification.

`Flutter` `Python` `TensorFlow Lite` `MobileNetV2` `Node.js` `Express` `MongoDB` `JWT`

- Trained and converted a MobileNetV2 model to TensorFlow Lite for fast mobile inference.
- Built a Flutter camera workflow for image capture and prediction display.
- Created a Node.js/Express backend with JWT authentication and MongoDB recognition history.
- Connected the end-to-end flow: Flutter client -> Node.js API -> Python AI inference service.
